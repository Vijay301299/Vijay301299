### 🧾 About me

I'm a **Cost Accountant at L.G. Balakrishnan & Bros. Ltd. (LGB)**, an NSE/BSE-listed auto component manufacturer in Coimbatore, Tamil Nadu. In the evenings, I run **VJ GST & Tax Consultancy** as an independent GST practice (Govt. of India Certified GST Practitioner).

I hold an MBA in Finance & Marketing, a B.Com in Professional Accounting, and an SAP S/4HANA FICO certification — and I like closing the gap between finance and technology by **building the tools I wish existed** for GST compliance, reconciliation, and small-scale finance automation.

Most of what I build is either:
- **Single-file AI-powered web tools**, using the Claude API — no backend, easy to run anywhere
- **Excel/VBA-based finance tools** — because a lot of finance/tax work still lives in spreadsheets, and it should work well there
